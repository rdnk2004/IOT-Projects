# TempSync: IoT Temperature Monitoring System

A cloud-based real-time temperature monitoring dashboard built with **Python**, **Django**, and **Supabase Cloud**.

The system simulates an IoT temperature sensor uploading readings to Supabase every 5 seconds, displaying real-time metrics, a dynamic trend graph, range filtering, and CSV exports on a dark-themed dashboard.

---

## Features
- **IoT Simulation**: Virtual sensor generating random readings (20°C - 40°C) every 5 seconds.
- **Dynamic Database Routing**: Reads/writes to **Supabase Cloud** when configured in `.env`, and automatically falls back to an offline local **SQLite database** (`data.sqlite3`) for seamless out-of-the-box offline testing.
- **Secure Authentication**: Built-in Django session authentication protecting views. The default superuser (`admin` / `admin123`) is bootstrapped automatically during initial database migrations.
- **Statistical Analytics**: Metric cards showing **Latest Temperature**, **Average**, **Minimum**, and **Maximum** values based on filtered queries.
- **Interactive Line Chart**: Chronological trend visualizations using Chart.js.
- **Log Data Table**: Chronological tabular log displaying date, time, and temperature with client-side pagination.
- **AJAX Polling**: Dynamically retrieves and visualizes updates every 5 seconds without full page refreshes.
- **CSV Data Exporter**: Instant download of filtered temperature records as a spreadsheet.

## Installation & Setup

### 1. Prerequisites
Make sure you have Python 3.8+ installed on your system.

### 2. Install Dependencies
Open a terminal in the project directory and install the packages:
```bash
pip install -r requirements.txt
```

### 3. Run Migrations
Run the Django migrations to configure authentication and sessions. This will automatically bootstrap the default credentials (`admin` / `admin123`):
```bash
python manage.py migrate
```

## Supabase Cloud Integration

To sync your data to the cloud:

1. **Create a table** named `temperature_readings` in your Supabase **SQL Editor**:
   ```sql
   CREATE TABLE temperature_readings (
       id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
       temperature float8 NOT NULL,
       date text NOT NULL,
       time text NOT NULL,
       timestamp float8 NOT NULL
   );
   ```
2. **Disable Row Level Security (RLS)** to allow anon inserts:
   ```sql
   ALTER TABLE temperature_readings DISABLE ROW LEVEL SECURITY;
   ```
3. Update your local `.env` file in the root directory:
   ```ini
   SUPABASE_URL=https://your-project-id.supabase.co
   SUPABASE_KEY=your-supabase-anon-public-key
   ```

## Operating Instructions

To start the system locally, run the following steps in separate terminal windows:

### Terminal 1: Run Web Server
Start the Django development server:
```bash
python manage.py runserver
```
Visit `http://127.0.0.1:8000/` in your browser. Log in using:
- **Username**: `admin`
- **Password**: `admin123`

### Terminal 2: Run Sensor Simulator
Start the simulator loop:
```bash
python sensor_simulator.py
```
You will see temperature logs and upload confirmations printing to the console every 5 seconds.
